SkillStar - What's new
======================

1.2.1
-----
- Continue a website download: the download is saved after every page,
  and a stopped or unfinished one goes on from where it stopped
  (right-click the website document -> Continue the download). The new
  pages go into the same document, which is then processed again; you
  can raise the number of pages too.
- Stopping a download that waits for a server that does not answer is
  quicker, and the page it waited for is tried again next time.

1.2.0
-----
- E-books: EPUB (2 and 3, chapters and the table of contents of the
  book), Kindle / Mobipocket (MOBI, AZW, AZW3, PRC, PDB), FictionBook
  (FB2, FBZ, FB2.ZIP), RTF, HTMLZ, DjVu (text layer, OCR for scanned
  pages through DjVuLibre) and comic books (CBZ, OCR). Copy protected
  (DRM) books are reported instead of giving garbage.
- Website download (Documents -> Website...): the pages of a site are
  downloaded following their links up to the depth you choose (0-5),
  at most the number of pages you give, on the same site (optionally
  only under the folder of the start page), robots.txt respected. The
  main text of every page (without menus, headers and footers) becomes
  one document, a page per web page with its title and address; the
  linked documents (PDF, EPUB, DOCX...) can be downloaded as separate
  documents. Live progress, and Stop keeps what was downloaded.
  The Crawl-delay a site asks for in its robots.txt is kept (e.g.
  15 s on codebase.c64.org), busy servers are tried again (429 / 503,
  Retry-After), and the download stops with a clear message when the
  site stops answering. Edit / history / login links of wikis are
  skipped.
- Fixed: after a very quick processing the busy bar could keep running.

1.1.1
-----
- AI token counter in the status bar: the tokens used by the AI
  features (input, output, prompt cache), counted from every answer of
  the Claude API, DeepSeek and the Claude Code CLI. Click it for the
  details per provider and model, this session and all time (with the
  cost the Claude Code CLI reports), and to reset the counter. The
  counts are kept across restarts.

1.1.0
-----
- RAG sources open the original PDF page (or image) in a page viewer
  with zoom and paging, next to the extracted text. The relevant part
  of the page and the search words are highlighted on the page image
  (from the PDF text layer, or read with OCR on scanned pages).
- RAG chat history: conversations are saved per skill and can be
  reopened, continued, renamed and deleted.
- Optional web search in RAG mode (Anthropic API): web claims are cited
  as [Wn] and the web pages are listed under the answer.
- Every answer shows where it comes from: knowledge base, web, or other
  (sentences without a citation, e.g. the AI's own knowledge).
- Vector (semantic) search for RAG: a local multilingual model
  (multilingual-e5-small, ~135 MB, downloaded once, offline and free)
  finds the passages that fit the question even when the words differ.
  Its results are fused with the full-text search; new documents get
  their vectors automatically. On macOS and Linux the same model
  runs in pure Rust (candle; ~490 MB download, slower indexing).
- RAG searches every document of the skill, also the ones left out of
  the package. A document can be left out of the RAG search one by one
  (right-click → Searched by RAG questions).
- The AI reads the question in the field of the skill (its title,
  description and keywords), so jargon typed without accents is not
  misread.
- The vector search is used once the index covers the documents; a
  half-built index no longer pulls the answers into the documents that
  already have vectors.
- The document list shows the selected rows clearly ("N selected", Esc
  clears it); the ticks only mean "in the skill package".

1.0.0
-----
- Package formats, chosen per skill, each in its own folder: Claude
  (Claude Code plugin folder, .plugin file, claude.ai skill ZIP), Agent
  Skills (Codex, Gemini CLI, Copilot, Cursor), ChatGPT (Custom GPT /
  Project), Gemini Gem, DeepSeek and RAG (chunks.jsonl for any LLM and
  vector store). The package preview shows the folders.
- Ask the documents in RAG mode: the AI writes extra search queries
  (synonyms, inflected and other-language forms), the local full-text
  index finds the passages, and the answer cites them as [n] - click a
  citation or a source to open the page. One skill or every skill.
- OCR language per document (Windows OCR language or Tesseract
  languages), and "Re-OCR with another language" for one or more
  documents. When the Hungarian OCR language is missing, the dialog
  shows how to install it.
- The AI theme is now "Neon", with a lot more glow.
- The PDF / OCR status is a small indicator in the status bar.
- Fix: in the light theme the red Stop button turned white on hover.
- Fix: a long skill name no longer pushes the toolbar buttons away.

0.1.0
-----
- First version: turns a pile of DOCX, PDF, PPTX, ODT, HTML, Markdown
  and text files into a Claude skill package (Claude Code plugin folder,
  .plugin file and a claude.ai skill ZIP).
- PDFs through PDFium (text layer, bookmarks as table of contents);
  pages without usable text are read with OCR: built-in Windows OCR or
  Tesseract. OCR mode per document (auto / always / never).
- Resumable processing: every finished page is saved at once, so a
  stopped or interrupted OCR run continues where it left off.
- Local SQLite database with full-text search (FTS5) over every page.
- Text viewer with page navigation, outline and editable page text to
  fix OCR errors.
- Generated SKILL.md, document index with table of contents, keyword
  index and per-document descriptions; package preview before building.
- Optional AI (off by default): document titles / descriptions, skill
  description, and questions answered from the documents.
- Drag and drop files and folders, GitStar themes, Hungarian / English
  UI, self-update.
